Quick start

From a clean CLI install to a verified project.

01

Install the CLI

Pin the published release with uv.

uv tool install ocae-cli --from git+https://github.com/xxammaxx/OpenCode-Agenten-Oekosystem.git@v1.0.4
02

Install the ecosystem

Run the preflight, review the dry-run when needed, then apply to your project.

ocae doctor .
ocae install .
03

Verify the runtime

Check integrity and let OpenCode discover the installed agents.

ocae verify .

Need a preview first? Run ocae install . --dry-run. Existing project content stays in scope and is preserved.

Governance

Safety is part of the install surface.

OCAE installs a project-local control plane that makes runtime capabilities explicit and fails closed when the source, scope, or environment cannot be verified.

↯

Fail-closed decisions

Capability profiles, MCP preflight, name-conflict checks, and source-lock integrity gate tool execution.

⌁

Preserve the project

Existing config, providers, models, user agents, and third-party plugins are merged conservatively, not silently replaced.

↩

Recoverable changes

Backups happen before mutation. Provenance, audit trails, idempotence, and rollback make the state reviewable.

∅

Secrets stay out

No secret contents are read by default, and MCPs remain disabled unless an owner explicitly enables them.
