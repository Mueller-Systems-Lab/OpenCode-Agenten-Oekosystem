# Repository reports

Reports are historical or release evidence. They explain completed governance,
security, architecture, compatibility, and runtime work without becoming part
of the primary installation path.

The final project closure report is
[`final-project-closure.md`](final-project-closure.md). Current product
installation and command reference belong in the root [`README.md`](../../README.md)
and [`ocae-cli.md`](../ocae-cli.md).
