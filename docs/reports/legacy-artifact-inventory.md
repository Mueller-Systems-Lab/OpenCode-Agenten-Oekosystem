## Guard rails

- `scripts/validate-ecosystem.mjs` `validateNoSilentLegacyFallback()` fails if the
  canonical plugin entry or installer template references
  `LEGACY_COMPATIBILITY_PATH`, `runtime/agent/run-state.mjs`, or
  `agent/start.mjs`.
- `scripts/install-governance.mjs` `validatePostApply` fails a fresh install if
  the installed hook still contains `LEGACY_COMPATIBILITY_PATH`.
- `.opencode/plugins/canonical-governance.mjs` and the installed hook write an
  `ocae.runtime-entry-failure.v1` record with `fallback_attempted=false` on every
  canonical-runtime entry failure and throw
  `RUNTIME_ENTRY_BLOCKED:CANONICAL_RUNTIME_UNAVAILABLE:<availability>:<detail>`.
- The soak tool `scripts/real-worker-soak.mjs` uses `--forced-canonical-failure`
  (was `--forced-legacy`); the success condition is now `NO_FALLBACK`
  (`fail_fast=true`, `run_context_created=false`), not a working legacy fallback.
