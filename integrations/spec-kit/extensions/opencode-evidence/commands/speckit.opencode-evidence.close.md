---

Produce the final classification from actual evidence and `$ARGUMENTS`. GREEN_SAFE is forbidden when a required contract, independent review, or runtime enforcement proof is missing. Include no more than three concrete NEXT actions and list remaining findings.

The last factual section of every German final report is `## Erforderliche Aktion durch den Nutzer`. Render only schema-valid `non_delegable_user_actions`; never copy NEXT actions, findings, recommendations, residual risks, or generic tool gaps into it. If no non-delegable action remains, write exactly `Keine Aktion durch den Nutzer erforderlich.`. GitHub actions require a `github_web` target and numbered visible controls, never CLI-only guidance.
